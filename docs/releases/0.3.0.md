# Herdr Link v0.3.0

Herdr Link 的首个统一系统版本。Relay、Gateway、Android 和桌面客户端统一采用 `0.3.0`，不再使用临时修复后缀或分散的组件 Release。

## 本版内容

- **Gateway 管理台**：电脑清单、在线状态与流量、限时接入码、独立注册凭据、禁用／恢复、撤销及容量调整。
- **Relay**：接入 Gateway 时保留原电脑身份和客户端授权；支持可靠的会话定位、终端与文件操作。
- **Android**：多电脑及工作空间分组、对话、终端、审批、文件和可选后台提醒。
- **桌面客户端**：Windows 与 Linux 同款原生界面；Linux 可直连同一用户的本机 Relay。
- **安装文档**：统一系统框图、各组件编译／部署、升级与安全说明。

## 升级已有安装

- Android `versionCode` 升至 **35**，继续使用原包名与签名；直接覆盖安装，不卸载旧版。
- Relay / Gateway 保留原服务名称、配置路径、主密钥和设备库。`0.3.0` 是新项目版本线，不对应上游 Herdr 的版本。
- 只重启要更新的 Relay / Gateway，不重启 Herdr 或 Agent。新 Gateway 可导入旧白名单，再逐台迁移独立凭据。
- 桌面客户端保留原应用标识、钥匙环和数据目录，升级不要删除配对数据。

## 支持范围

- 完整服务端部署包：Linux x86_64。macOS / ARM64 服务端仅提供 CI 独立二进制，不包含在本 Release。
- Android 9 及以上；发布 APK 沿用现有调试证书，不是 Play 商店签名。
- Windows / Linux 桌面包尚未签名；Linux 需 GTK 3、WebKitGTK 4.1、libsecret 与 Secret Service。macOS 客户端暂不提供签名／公证包。
- 后台通知依赖客户端常驻连接，断网和系统省电可能影响提醒。

## 验证

各组件由同一源码提交、同一次 CI 构建生成。发布前校验 CI 归档散列、逐文件散列、Android 包名／版本／ABI／固定证书；服务端执行隔离启动与配对测试，桌面执行各自平台测试和 Linux 图形／钥匙环 smoke test。不是所有 Android 真机、Linux 发行版或桌面环境的完整验收。
