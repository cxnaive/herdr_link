# Herdr Link v0.3.3

本次发布基于 `2eac8ef` 的最新功能代码，整合多客户端配色、桌面历史定位、Pi / Oh My Pi 交互，以及 Windows 原生和 WSL Relay 本机连接。Relay、Gateway、Android 和 Windows / Linux / macOS Desktop 统一为 **0.3.3**。

## 新增与修复

- **统一配色**：Android、桌面及 Web 新增薄荷深色、午夜蓝、石墨紫、云白蓝、暖纸棕。保留原有默认与主题选择，在本机记住偏好；切换不重连，也不清除草稿或待确认发送。Android 支持预览后应用；桌面应用与终端深浅色独立设置；Android 和新增 Web 配色的终端保持深色。
- **桌面历史**：打开或刷新对话后定位到最近已加载消息，继续跟随新消息；主动向前阅读和加载旧页时保留位置。“回到最新”清除搜索并跳到已加载内容末尾，无需重新下载历史。
- **Pi / Oh My Pi**：Android 普通消息使用正常发送接口，不再要求可选的阻塞输入桥。支持当前 Pi 选择器与文本输入、OMP 审批 / Ask 及可识别 HTML 表单；多选用 Space 切换，记住审批范围不等于授权。表单逐字段操作，到最终提交控件才发送；私密输入和未知布局仍需显式使用终端。旧弹窗不会向切换后的 Agent 提交。
- **Windows Relay 下载**：新增 Windows x86_64 完整 ZIP，保留现有配置和配对。安装不再请求普通用户不具备的审计策略权限。
- **Windows Codex**：通过进程、端口或文件锁等证据确认当前会话，提供结构化历史、发送、审批和运行状态；共享运行时支持模型 / 思考强度设置，内嵌运行时仍需在终端修改。证据不明确时保持未确认，不按最新日志猜测。修复 Windows 短路径名和大小写别名导致的误拒绝，继续拒绝符号链接 / 目录联接及锁归属不明确的情况。
- **Windows 本机连接**：桌面端可直接发现并连接当前 Windows 用户的 Relay，或已运行 WSL 发行版默认 Linux 用户的 Relay，无需 Gateway 或复制邀请。不同发行版即使端口相同也保持独立；重连保留凭据与草稿。Linux 原有本机直连继续保留。

配色入口：Android **设备 → 主题配色**；桌面 **外观 → 应用主题**；Web **Settings → Appearance → Theme**。

## 下载与升级

- **Android 9+**：普通手机选择 `arm64-v8a`，另有 `armeabi-v7a` / `x86_64`。versionCode **38**，继续使用原包名 `dev.herdr.companion` 和原签名；直接覆盖安装，不要卸载旧版。
- **Relay / Gateway**：Linux amd64 / arm64 完整部署包；Windows x86_64 提供 Relay，不提供 Windows Gateway。保留服务名、主密钥、配置和设备 / 管理数据库，只按需重启对应服务，不重启 Herdr 或 Agent。
- **Windows Relay**：Windows 10/11 x86_64、PowerShell 7 和原生 Herdr（集成测试固定为 0.9.5）。保持 Herdr 的 ConPTY 配套文件完整，与 Herdr 使用同一普通用户；按包内 `README.md` / `install.ps1` 安装并前台运行，不安装 Windows Service。保留 `%LOCALAPPDATA%\HerdrLink\relay`，不要同时启动两个实例使用同一配置。
- **Windows Desktop**：x86_64 便携 ZIP，完整解压后运行 `Herdr Desktop.exe`，保留同目录的 `ghostty-vt.dll`；PDF 预览需要 WebView2。
- **Linux Desktop**：amd64 / arm64 Debian 包、归档与用户安装脚本；需要图形桌面、GTK 3、WebKitGTK 4.1、libsecret 和已解锁的 Secret Service。
- **macOS Desktop**：Universal DMG 同时包含 Apple Silicon / Intel；拖入 Applications，无需 Go / Xcode。替换 App 时保留 Keychain 和用户配置。

本机直连需要同时更新 Relay 与桌面端；WSL 发行版须已运行，并有 Python 3.9+。发现列表本身不创建邀请，选择连接后才授权。macOS 本机 Relay 自动发现尚未接入，继续使用独立配对邀请。

所有下载使用同一 Release 的 `SHA256SUMS.txt` 校验；完整步骤见附件 `INSTALL.md`。共 **19 个附件**，含 `BUILD-INFO.json`、`SHA256SUMS.txt` 和安装说明，均由同一提交、同一次统一 CI 构建提供。发布不重新签名，不覆盖历史附件，也不自动部署线上服务。

## 支持范围与安全说明

- Windows / Linux 桌面和 Windows Relay 为未签名预览包。Android 沿用 Pocket 原来的固定调试证书，不是 Play 商店签名。
- macOS App 为 **ad-hoc 签名，无 Developer ID 签名，未经 Apple 公证**。最低系统声明为 macOS 12；CI 使用 macOS 15 Apple Silicon / Intel 原生 runner 验证同一 DMG。确认来源与校验一致后，若系统阻止启动，可在“系统设置 → 隐私与安全性”中选择“仍要打开”；不要关闭全局安全检查。
- Pi / OMP 交互核验基线为 **Pi 1.5.2 / OMP 18.18.6**，不代表支持所有扩展或未来布局。具体边界见[交互支持说明](https://github.com/cxnaive/herdr_link/blob/v0.3.3/docs/pi-omp-current-support.md)。Windows 不提供 Pi Unix 本地命令桥、Unix 信号重载或插件自更新。
- 自动化通过不等于所有系统、中文输入法、通知、文件选择及 WSL 发行版均已人工验收。发布包不包含个人凭据或会话数据；不确定的会话身份和发送结果继续按未确认处理，不自动重发。
