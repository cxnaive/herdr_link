# Herdr Link v0.3.4

本次补齐 Android 和 Windows / Linux / macOS 原生客户端的离线数学公式显示，同时收录 v0.3.3 之后的邀请权限下拉菜单、桌面 Agent 创建错误提示和英文文档。Relay、Gateway、Android 和 Desktop 统一为 **0.3.4**；Web 客户端未新增公式渲染。

## 新增与修复

- **离线 TeX 数学公式**：Android 对话及 Markdown 文件预览、桌面对话回答及 Markdown 预览支持行内 `\(...\)` / `$...$`，以及独立公式 `\[...\]` / `$$...$$`。支持常用分数、求和、上下标、矩阵、`\mathcal`、`\mathbf`、`\underbrace` 和 `\text{中文}` 注释；不需要外部公式服务、CDN 或安装 TeX。Android 使用原生 Canvas，桌面使用内嵌排版引擎和原生矢量绘制。
- **长公式与主题**：Android 长公式先适配消息宽度，点击可放大、横向查看并复制 TeX；桌面独立公式可横向滚动、右键复制 TeX。公式跟随应用深浅配色，中文使用系统字体。保留原始消息，无需迁移已有对话。
- **稳健回退**：代码块及行内代码不作为公式解释。尚未闭合的流式公式、未知命令或超过安全限制的内容保持可读源码，不阻断后续正文。异步排版不改变当前 Agent、草稿和桌面主动阅读历史的位置。
- **Android 邀请权限**：创建邀请时从下拉菜单选择“只读（reader）”或“控制者（controller）”，默认仍为只读。只有当前控制者能创建邀请，选择只影响新设备；取消不发送请求，不更改当前凭据。
- **桌面创建失败提示**：Agent 创建失败时展示明确的红色提示和原因，保留表单内容供修改。无法确认的结果仍标记为待确认，不误报为确定失败。
- **英文文档**：新增英文系统 README，发布后同步中英文和各客户端的下载链接。

## 下载与升级

- **Android 9+**：普通手机选 `arm64-v8a`，另有 `armeabi-v7a` / `x86_64`。versionCode **39**，沿用 `dev.herdr.companion` 和原签名；直接覆盖安装，**不要卸载旧版**，以保留配对、草稿和设置。Release 附件是 Release 构建，Debug APK 只留在 CI。
- **Windows Desktop**：x86_64 便携 ZIP，完整解压后运行 `Herdr Desktop.exe`，保留同目录的 `ghostty-vt.dll`；PDF 预览需要 WebView2。
- **Linux Desktop**：amd64 / arm64 的 Debian 包、便携归档和用户安装脚本；需要图形桌面、GTK 3、WebKitGTK 4.1、libsecret 和可用的 Secret Service。中文显示需要系统中文字体，Ubuntu 可安装 `fonts-noto-cjk`。
- **macOS Desktop**：Universal DMG 支持 Apple Silicon / Intel，拖入 Applications；替换 App 时保留 Keychain 和用户配置，不需要 Go、Node 或 TeX。
- **Relay / Gateway**：Linux amd64 / arm64 完整包，以及 Windows x86_64 Relay ZIP。本次公式渲染不改变消息协议，使用已有兼容 Relay 无需为公式功能重新配对或更新服务器。若更新服务端，保留主密钥、配置、设备和管理数据库，只重启需要更新的服务，不重启 Herdr 或 Agent。

所有正式附件来自**同一提交、同一次完整 CI 构建**；发布器校验源码、平台、APK 包名／版本／ABI／原证书及逐文件散列后才公开。共 **19 个附件**，含 `INSTALL.md`、`BUILD-INFO.json` 和 `SHA256SUMS.txt`。安装时用同一 Release 的校验文件核对下载；不混用不同构建的组件。

## 支持范围与安全说明

- 这是常用数学表达式排版，不是完整 LaTeX 文档编译器；不支持执行外部资源、自定义文档和任意扩展。两套原生引擎的命令支持和细节排版可能不同；不支持的内容回退源码。缺少中文字体时桌面公式也会回退，不将字符静默丢弃。
- Web 客户端保持原样，终端视图也保持 ANSI 文本显示。
- Android 沿用 Pocket 原来的固定调试证书，不是 Play 商店签名；Windows / Linux 桌面及 Windows Relay 仍为未签名预览包。
- macOS App 为 **ad-hoc 签名，没有 Developer ID 签名，未经 Apple 公证**。最低系统声明为 macOS 12；CI 在 macOS 15 Apple Silicon / Intel 原生 runner 上验证同一个 Universal DMG，不代表全部旧系统和人工交互已验收。核对来源和校验后，必要时通过“系统设置 → 隐私与安全性 → 仍要打开”放行，不要关闭全局安全检查。
- 发布不部署线上服务，不更换任何已有身份或签名，不覆盖或删除旧 Release。
