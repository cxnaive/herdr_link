# Herdr Link v0.3.1

为 Linux ARM64 增加完整的 Relay、Gateway 和桌面客户端下载，继续使用同一套 CI 构建与发布流程。

## 新增

- Relay / Gateway：Linux ARM64 完整部署包，包含配置、systemd 模板和部署指南。
- Linux ARM64 客户端：Debian 包、便携归档与免 root 安装脚本；与 x86_64 客户端共用对话、终端、审批、文件和本机 Relay 发现功能。
- 两种 Linux 架构分别在原生 runner 上验证，发布检查拒绝架构、源码或散列不匹配的附件。
- 仓库地址统一为 `cxnaive/herdr_link`，修正下载链接和 CI 签名／发布的仓库校验。

## 下载与升级

运行 `uname -m`：`x86_64` 选择 `linux-amd64`，`aarch64` 选择 `linux-arm64`。下载所需附件及 `SHA256SUMS.txt`，按照 `INSTALL.md` 安装。

- Android versionCode 升至 **36**，沿用原包名和固定签名，直接覆盖安装以保留配对数据。
- Relay / Gateway 保留原服务名、配置、主密钥、设备库及 Gateway 管理库。更新二进制只需重启对应服务，无需重启 Herdr 或 Agent。
- 桌面客户端保留原应用标识、钥匙环和数据目录。

## 支持范围

服务端完整包支持 Linux amd64 / arm64；Linux 桌面需要图形环境、GTK 3、WebKitGTK 4.1、libsecret 和已解锁的 Secret Service。桌面包未签名。Android 9 及以上，Windows 提供 x86_64 便携包；macOS 仍无签名／公证客户端安装包。

所有 17 个附件由同一提交、同一次 CI 构建收集，包含安装说明、构建来源和校验清单。不会重新签名或替换旧版附件。
