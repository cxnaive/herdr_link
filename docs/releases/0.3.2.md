# Herdr Link v0.3.2

新增 macOS Universal DMG 桌面预览包，并包含近期的终端保留、Agent 运行数量和 Gateway 管理员密码改进。Relay、Gateway、Android、Windows/Linux/macOS Desktop 使用同一项目版本。

## 新增与修复

- macOS：同一 DMG 内包含 Apple Silicon 和 Intel 应用，拖入 Applications 即可安装，无需 Go 或 Xcode。与其他桌面端共享多电脑配对、对话、终端、审批和文件界面。
- Android / Desktop：电脑分组展示运行中、待处理和待确认 Agent 数量，不受搜索与折叠影响；纯终端单独统计，离线不展示过期运行数。
- Relay / 客户端：Agent 退出后仍可访问保留的终端面板，不再借用已退出 Agent 的会话身份；旧请求不能投递到 shell 或下一个 Agent。
- Gateway：支持从有界标准输入设置自定义管理员密码，使用加盐密码散列，保留电脑注册凭据、证书和配对。

## macOS 安装与安全提示

下载 `herdr-link-desktop-0.3.2-macos-universal.dmg` 和 `SHA256SUMS.txt`，执行 `shasum -a 256 文件名.dmg` 与清单对照。打开磁盘映像，将 `Herdr Desktop.app` 拖入 Applications，再弹出映像并启动。

这是 **ad-hoc 签名、无 Developer ID 签名、未经 Apple 公证的预览版**。首次启动可能被 macOS 阻止；仅在确认官方来源和校验一致后，在“系统设置 → 隐私与安全性”中选择“仍要打开”。不要关闭系统全局安全检查；企业管理策略可能不允许例外。

App 最低系统版本声明为 **macOS 12**。本次 CI 在 **macOS 15 Apple Silicon 与 Intel** 原生 runner 上测试；Intel 验证的是 Apple Silicon runner 生成的同一 DMG，而不是重建的替代包。检查包括应用身份、两种 Mach-O 架构、签名、安装前后字节、原生终端、Keychain、UI 启动和 PDF。更早系统、中文输入法、通知、文件选择/拖放/剪贴板等完整人工场景仍需验收。

此下载是 Mac **客户端**，不增加 Mac 本机 Relay 自动发现，也不改变 Codex 进程核验的平台支持范围。

## 下载与升级

- Android versionCode **37**，保留 `dev.herdr.companion` 与原有签名，直接覆盖安装，不要卸载。
- Relay / Gateway：Linux amd64 / arm64 完整部署包；保留服务名、配置、主密钥、设备库、管理库，仅按需重启对应服务。
- Windows：x86_64 便携 ZIP。Linux：amd64 / arm64 Debian 包、归档和用户安装脚本。桌面已有配对、草稿及密钥存储保持不变。
- 所有客户端均需独立配对；发布包不包含个人凭据或会话数据。

共 **18 个附件**由同一源码提交、同一次统一 CI 构建产生，含 `INSTALL.md`、`BUILD-INFO.json` 和 `SHA256SUMS.txt`。发布只提升已经验证的 CI 字节，不重新签名、不覆盖历史附件、不自动部署。
